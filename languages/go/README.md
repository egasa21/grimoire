# Go

Practical defaults for writing and organizing Go code. Follow the repository's
existing conventions and adjust these recommendations to its responsibilities.

- [Conventions](conventions.md) — packages, dependencies, errors, concurrency, data, and tests.
- [Project structure](project-structure.md) — a simple, feature-oriented monolith that can grow with the application.
- [Reusable agent instructions](../../templates/agents/go/AGENTS.md) — a standalone file to copy into any Go repository.

Start with the official [Go documentation](https://go.dev/doc/). These guides
summarize engineering choices; the language and standard-library documentation
remain the authority for behavior.
