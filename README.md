review checklists, and reusable instructions for AI coding agents.

## Philosophy

Keep things simple, practical, and easy to maintain. Start with a real problem;
add structure when it helps. These notes are defaults to reason from, not an
architectural framework.

Add language guides under `languages/`, general guidance under `fundamentals/` or
`practices/`, and reusable files under `templates/`. Create directories when there
is something useful to put in them.
